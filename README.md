# Task Login Portal

A minimalist orange and light blue login portal with administrator and employee dashboards.

## Features

- Admin login and employee login
- Admin can create user credentials
- Admin can suspend or activate users
- Admin can assign tasks to employees
- Employee can update task status and remarks
- Deadline alerts for near-due and overdue tasks
- Dashboard statistics
- Responsive layout for desktop, tablet, and mobile

## Notes

This is a front-end demo using React state only. For production, connect it to a backend database such as Firebase, Supabase, Laravel API, Node.js/Express, or PHP/MySQL.
